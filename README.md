# mini-project-2_pemogramanWEB
Projek sebuah Website manajemen stok produk di toko "Galeri Laptop" yang berfungsi untuk mengelola data produk seperti nama produk, kategori, harga dan jumlah stok secara efesien, lebih terstruktur, dan mudah.
# Manajemen Stok Produk Elektronik

## Deskripsi

Website Manajemen Stok Produk Elektronik merupakan aplikasi berbasis PHP dan MySQL yang digunakan untuk mengelola data produk secara sederhana dan terstruktur.

Website ini membantu pengguna dalam melihat, menambahkan, mengubah, dan menghapus data produk. Data produk yang dikelola meliputi nama produk, kategori, harga, dan jumlah stok.

Kategori produk yang digunakan dalam sistem ini adalah:
- Laptop
- iPad

## Fitur

Beberapa fitur yang tersedia pada website ini yaitu:

- Menampilkan daftar produk
- Menambahkan produk baru
- Mengubah data produk
- Menghapus produk
- Menampilkan kategori produk
- Menampilkan harga produk
- Menampilkan jumlah stok produk
- Mengelola data produk menggunakan database MySQL

## Teknologi yang Digunakan

Website ini dibuat menggunakan:

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- Visual Studio Code
